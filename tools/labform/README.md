# 시험기록부 엑셀 양식 정리 도구

회사 시험기록부 양식(전체 43종 예정)을 한 기준으로 정리하는 도구다. StackPilot 프로그램에는 들어가지 않는다.
지금까지 5종(먼지, 가스 SOx·NOx·CO, 사이안화수소, 벤조(a)피렌, VOCs)을 정리했다.

**회사 양식 파일(원본·결과물)은 저장소에 올리지 않는다.** 작업은 `tools/labform/work/` 아래에서 한다 (`.gitignore`에 들어 있다).

## 사용자가 정한 기준

1. 서명란(담당·기술책임자) 크기가 어느 양식을 뽑아도 같아야 한다.
2. 중요한 내용이 잘리면서 쪽이 나뉘면 안 된다.
3. 테두리: 칸 배치(형태)는 양식마다 달라도 서식(양식)은 같아야 한다. 선 자리는 두고 굵기를 맞춘다.
4. 글자가 잘리거나 칸이 모자라면 안 된다. 단어 중간에서 두 줄로 나뉘면 안 되고, 숫자·날짜가 ###으로 찍히면 안 된다.
5. 모든 시트(rawdata·계산과정 포함)의 글씨체는 맑은 고딕, 굵은 글씨를 쓰는 곳도 같게. 날짜는 yyyy-mm-dd.
6. 문서번호(예: `■ MAMO-QP-14-01`)가 기록부 시트의 모든 쪽 바닥글(끝머리)에 나와야 한다. 로우데이터·계산과정 시트에는 넣지 않는다.
7. 정렬(가운데 정렬 등)이 같은 기준을 따라야 한다.
8. 수식·그림 위치가 같은 기준을 따라야 한다.

9. 시료정보·분석정보 칸에는 원본처럼 예시 값을 넣어 둔다 (나중에 같은 모양으로 쓰도록). 예시 이름은 오설록.
10. 위첨자·아래첨자를 맞춘다: 단위 Sm3·m3의 3은 위첨자, 화학식 숫자(NH3·H2S·H2O2·SO2·O2…)와 RRFavg의 avg는 아래첨자.

`verify.py`가 ①~⑨를 차례로 검사한다 (⑨ 위첨자·아래첨자·예시 이름). 모두 "통과"여야 끝난 것이다.

## 서식 기준 (`form_style.py`, `layout_rules.py`)

| 기준 | 내용 |
|---|---|
| 테두리 | 바깥 테두리와 쪽이 나뉘는 경계 = 굵은 선, 안쪽 = 가는 선. 표 아래 내용 없는 줄과 혼자 남은 짧은 선은 지운다 |
| 제목·서명란 | 제목 맑은 고딕 26 굵게, 서명란 "담 당" / "기술책임자" |
| 정렬 (세로는 모두 가운데) | 번호·항목명·회색 머리 칸·표 안의 값 = 가운데. 기본 정보 내용 칸(시험항목~검정곡선 작성)·기호 설명("C : …")·긴 설명 글 = 왼쪽(세 글자 이하 단위 칸은 가운데). 한 줄 전체 머리 = 왼쪽. 도형 위에 얹은 글자 칸(VOCs 온도 그래프 등)과 칸에 직접 쓴 수식은 그대로 |
| 수식 | 글자 크기 20pt, 앞쪽 위치 맞춤용 빈칸 지움, 왼쪽 정렬 수식 단락. 계산식 칸에서 기호 설명 위 줄들의 세로 가운데, 가로는 "* ○○ 농도" 글 뒤(없으면 16px 들여쓰기)부터 기호 설명 열 앞까지. 수식이 줄보다 크면 그 줄을 늘린다 |
| 글꼴 | 모든 시트의 칸·칸 안 일부 글자 서식·메모·글상자·차트를 맑은 고딕으로 (수식 글꼴 Cambria Math만 그대로) |
| 굵기 | 굵게: 제목, 기본 정보 줄(시험항목·의뢰기관·측정대상·시료인수일·분석일자·시험방법·분석기기)의 값 칸(빈 입력 칸 포함). 그 밖은 굵지 않게 |
| 글자 맞춤 (`content_rules.py`) | 칸에 안 들어가는 글은 띄어쓰기 자리에 줄바꿈을 직접 넣는다 (Excel은 한글을 글자 단위로도 줄바꿈해서 자동 줄바꿈에 맡기지 않는다). 띄어쓰기 없는 긴 영문 이름은 "-" 뒤·"(" 앞에서 나눈다. 좁고 세로로 긴 칸은 90° 돌려 세로로 쓴다. 그래도 안 되면 그 칸 글자 크기를 줄인다(8pt까지). 글자 폭은 칸 안쪽 너비의 92%까지만 쓴다 |
| 숫자·날짜 | 날짜·숫자·수식 칸은 "셀에 맞춤"(### 대신 작게). 옆 빈칸으로 넘쳐 보이는 글자 결과 수식 칸은 예외. 날짜 표시 형식 yyyy-mm-dd |
| 예시 값 | 사용자가 준 먼지 원본 기록(A16)의 값을 2027년 날짜로: 의뢰기관 "수도권대기환경청 대기총량과", 측정대상 "대일개발(주) #A16", 시료채취일 2027-03-31, 인수 시각 17, 분석일자 2027-04-01, 시험검사기간 2, 서명란 "오 설 록 (인)"(담당·기술책임자 모두), 허가배출기준 "8(12)"(머리 칸 오른쪽 값 칸이 있는 양식만), 시료명 "0331-DIG-#A16-P-1"(시료명 표 첫 줄. 계산과정에서 끌어오는 칸이면 수식을 따라가 원래 입력 칸에, 수식이 붙이는 꼬리 "-1"은 빼고). 모든 양식 같은 값. 이미 수식·글("현장분석" 등)이 있는 칸은 그대로 |
| 그림(차트) | 놓인 빈 영역(가로선으로 막힌 빈 줄, 표 너비 전체)에 상하좌우 8px 여백으로 채운다. 너비·높이 5px 미만인 보이지 않는 그림은 지운다. 인쇄 범위 밖 그림은 그대로 |

테두리는 파일의 XML에서 직접 읽는다. openpyxl은 병합 칸을 읽을 때 테두리를 바꿔 넣어서 믿을 수 없다.

## 기준을 구현한 방식 (`std.py`)

| 기준 | 방식 |
|---|---|
| 서명란 크기 | 1행에서 "담당"·"기술책임자" 칸을 찾아, 칸 하나의 너비를 17.5자(`SIGN_W`), 1·2행 높이를 30.75 / 59.25pt로 맞춘다 |
| 인쇄 크기 | 인쇄되는 열 너비의 합을 모든 양식에서 1048px(`TOTAL_PX`)로, 여백도 같게. 배율은 66 %로 고정(`WORST_SCALE`). "한 쪽 너비에 맞춤"은 엑셀(맑은 고딕, 한 글자 8점)에서 71 %, LibreOffice에서 66.5 %로 달라 엑셀에서 쪽 끝 표가 다음 쪽으로 밀렸다. 66 %면 어느 프로그램에서도 너비가 들어가고 쪽 높이가 같다 |
| 쪽 나눔 | A열에 항목 번호가 있는 줄을 항목의 시작으로 보고 그 경계에서만 나눈다. 병합 칸 중간은 나누지 않는다. 한 쪽(`PAGE_PT`)을 넘으면 내용 없는 큰 줄을 35%까지, 그래도 넘으면 줄 전체를 3%까지 줄인다. 쪽 나눔은 수동 쪽 나누기로 적는다 |
| 글자 잘림 | 열이 좁아진 칸만 본다. 원래는 들어갔는데 넘치게 된 칸은 줄바꿈을 켜고, 줄 수가 늘면 줄 높이를 늘린다. 글자 폭은 추정값이다 |
| 테두리·정렬·글꼴·수식·그림 | 아래 서식 기준을 따른다 |
| 문서번호 | 칸에 적힌 문서번호를 지우고 기록부 시트 바닥글 오른쪽에 넣는다. 로우데이터·계산과정 시트에는 넣지 않는다 |
| 쪽 높이 | 엑셀 '너비에 맞춤' 배율이 70%까지 커져도 한 쪽에 들어가게 6% 여유를 둔다. 모든 줄 높이를 고정(customHeight)해 엑셀이 열 때 줄 높이를 다시 맞추지 않게 한다 |
| 위첨자·아래첨자 | `scripts_rule.py`: 글자 값은 그대로 두고 서식 있는 글자로만 바꾼다 (수식 참조에 영향 없음). 시료명(…-CS2-1-1)은 건드리지 않는다 |

배율을 숫자로 고정하지 않는 까닭: 고정하면 프린터·글꼴에 따라 마지막 열이 다음 쪽으로 넘어갈 수 있다 (LibreOffice에서 실제로 넘어갔다).

## 파일

- `tplkit.py` — xlsx의 XML을 직접 고치는 도구 (그림·도형·차트를 잃지 않으려고 openpyxl로 저장하지 않는다)
- `std.py` — 위 인쇄 기준
- `prep.py` — 양식별 정리(예시 값 비우기, 수식 바로잡기) 후 `std.py` 적용. 지금은 5종
- `refill.py`, `compare.py` — 정리본에 원본 예시 값을 도로 넣어 다시 계산한 결과가 원본과 같은지 비교
- `form_style.py` — 테두리 굵기·제목·서명란·머리 정렬, `layout_rules.py` — 정렬·수식·그림 위치, `content_rules.py` — 글꼴·굵기·글자 맞춤·날짜·예시 값
- `verify.py` — 9가지 기준 검사: `python3 -I tools/labform/verify.py $W/out --pdf $W/out/pdf [--ref 원본폴더]`
- `lo.sh` — LibreOffice로 강제 재계산(xlsx)·PDF 변환, `errs.py` — 오류 칸 찾기, `pages.py` — PDF 첫 쪽을 나란히 그림으로

## 쓰는 법

```bash
W=tools/labform/work && mkdir -p $W/orig $W/out $W/fill
# $W/orig 에 양식을 dust.xlsx gas.xlsx hcn.xlsx bap.xlsx vocs.xlsm 이름으로 둔다
python3 -I tools/labform/prep.py $W/orig $W/out            # 정리본 만들기 (바꾼 내용이 줄줄이 찍힌다)
tools/labform/lo.sh $W/out pdf                             # 다시 계산 + PDF
python3 -I tools/labform/errs.py $W/out/lo                 # 오류 칸이 0이어야 한다
python3 -I tools/labform/verify.py $W/out --pdf $W/out/pdf # 9가지 기준이 모두 "통과"여야 한다
python3 -I tools/labform/pages.py $W/out/pdf $W/pages.png 60
python3 -I tools/labform/refill.py $W/orig $W/out $W/fill  # 원본 예시 값 도로 넣기
tools/labform/lo.sh $W/fill
python3 -I tools/labform/compare.py $W/orig $W/fill/lo     # 고친 오류 칸 말고는 원본과 같아야 한다
```

## 새 양식을 더할 때

1. 시트·수식·그림을 먼저 읽는다 (입력 칸, 수식 칸, 붙여 넣은 사진, 쪽 나눔, 문서번호 칸).
2. `prep.py`에 양식별 함수를 더한다: 예시 값 비우기, 빈 양식에서 오류(`#REF!`, `#DIV/0!`)가 안 보이게 수식 감싸기, 찾은 수식 오류 바로잡기. 공통으로 하는 것은 아래와 같다.
   - 시험기한: `WORKDAY(인수일, IF(시<13, 기간-1, 기간))` — `DAY()`로 날수를 꺼내던 수식은 31일을 넘으면 틀린다
   - 시험검사기간 칸의 표시 형식: `d"일"` → `0"일"`
   - 시료인수일은 시료채취일을 따라가게 (다르면 직접 적는다)
   - 붙여 넣은 사진(기기 출력, 허가기준 표 등)은 지운다. 도형(계산식)·차트는 둔다
3. 마지막에 `finish_print(b, [(기록부 시트, 인쇄 범위)], [(다른 시트, 가로 여부)])`.
4. `refill.py`·`compare.py`의 `PAIRS`에 더하고 위 순서대로 확인한다.

43종 대부분은 사이안화수소처럼 흡수액·분광광도계 양식일 것으로 본다. 양식이 더 모이면 양식별 함수를 물질마다 쓰지 않도록 공통 틀로 묶는 것이 좋다.

## 5종에서 바로잡은 수식 오류

- VOCs 벤젠: 시료 1의 최종 결과값 칸(H34)에 수식 대신 숫자 6 → 다른 줄과 같은 수식
- VOCs 첫 장: 물질 이름이 빈 줄의 `#REF!` → 빈칸
- 벤조(a)피렌: 검증시료 평균(B87)이 다른 줄(78~81행)을 봄 → 77~78행
- 벤조(a)피렌: 검정곡선 표와 표준용액 평균 면적이 주입 순서(13~18행)에 고정 → STD 이름으로 찾음
- 벤조(a)피렌: 기기 시트를 `INDIRECT`로 찾던 수식 → 시트를 바로 가리킴
- 먼지: 표준산소 없이 실측산소만 적으면 `#VALUE!` → 보정값이 있을 때만 보정값 사용. 먼지량 "0" 글자 → 숫자 0
- 사이안화수소: 첫 장의 희석배수 1 → 계산과정 값을 따라감

## 아직 정하지 않은 것 (사용자에게 물어 둔 것)

1. (정함) 담당·기술책임자 이름은 원본 기록대로 예시로 넣는다.
2. VOCs 물질별 시트의 인쇄 범위를 A~J열(본문)로 줄였다. 원본은 오른쪽 기기 자료 칸(AE열)까지 찍었다.
3. 사이안화수소 계산식의 "×10"(250 mL ÷ 분취 25 mL)이 숫자로 박혀 있다. 양식 그대로 뒀다.

## 한계

- 이 환경에는 Excel과 맑은 고딕 글꼴이 없다. 계산은 LibreOffice로 확인했다. 인쇄 확인용으로 맑은 고딕·돋움·굴림을 나눔바른고딕(숫자 폭이 맑은 고딕보다 약 6 % 넓음)으로 바꿔 찍으므로, LibreOffice에서 들어가면 Excel에서도 들어간다. 실제 Excel 인쇄 미리보기로 한 번 확인하는 것이 좋다.
- 계산과정 시트는 "한 쪽 너비에 맞춤"이라 LibreOffice PDF에서는 Excel보다 조금 작게 보인다 (쪽 나눔은 Excel 기준으로 정해 둠).

## LibreOffice로 확인할 때 주의

- LibreOffice는 Excel 수식 개체를 한 줄 텍스트로 그린다. 수식은 위치·크기만 보고, 모양은 Excel에서 본다.
- 여러 줄 칸(VOCs 물질별 시트의 조작조건 등)을 변환할 때마다 다르게 그리는 경우가 있다(같은 파일을 두 번 변환해 한 번은 줄이 붙음). 파일 문제가 아니니 한 번 더 변환해 본다.


## 기준 관리 (자릿수·방법검출한계·불검출·허가배출기준 초과·산소 보정)

### 판정 규칙 (모든 기록부 결과 수식이 같은 규칙)

| 규칙 | 내용 | 근거 |
|---|---|---|
| 계산·표시 | 계산값을 계산 자릿수로 4사5입 → 최종 자릿수로 4사5입해 표시. 계산 자릿수 = 최종 자릿수 + 1 | 총칙 ES 01000.b 1.6·2.14.2 |
| 수치 맺음 | 계산 자릿수까지 계산(아래 버림) → 최종 자릿수로 한 번 4사5입 (KS Q 5002 4.2.2.2, 맺음은 한 번에): `ROUND(TRUNC(ROUND(R,계산+5),계산),최종)` | 총칙 1.6·2.14.2 |
| 불검출 | 반올림한 값이 방법검출한계 **미만**일 때만 불검출. **같으면 값**. 판정은 최종 자릿수로 반올림한 값(성적서 값)으로 | 총칙 2.14.3 |
| 초과 | 허가배출기준 칸(예 `8`, `8(12)`, `1.6\n(12)`)의 괄호 앞 숫자보다 **크면** 값 옆 " (초과)" + 빨간 조건부 서식. 같으면 초과 아님. 원래의 제각각이던 초과 표시는 지움 | |
| 산소 보정 | 허가배출기준 괄호 안 숫자 = 표준산소농도(%) → 양식의 표준산소 입력 칸에 자동 연결. 괄호가 없으면 보정 안 함. 초과 판정은 보정한 값으로 | |
| "숫자(산소)" 계산값 | 불소 등에서 계산과정이 "0.1(12)"처럼 내면 괄호 앞 숫자로 판정·표시하고 "(12)"는 뒤에 그대로 | |
| 원문 대조 | 물질별 원문의 결과 자릿수·단위·버전과 다르면 원문 값으로 고치고 기준 시트 비고에 근거를 남김 | 각 시험법 8.0 결과 표시 |

허가배출기준 라벨은 양식마다 "허가배출기준"·"배출허용기준"·"배출허가기준"으로 다르다. 셋 다 인식하되 글자는 바꾸지 않는다.

### 기준 시트

각 기록부에 숨김 시트 `기준`: 물질·시트·결과 칸·공정시험기준·계산 자릿수·최종 자릿수·방법검출한계·정량한계·단위·비고·판정 자릿수(수식).
기록부의 방법검출한계·정량한계·시험방법 칸은 `='기준'!…`. 암모니아 BA·전체 시트처럼 다른 시트 값을 쓰던 칸은 그 연결을 유지.

### 파일

- `run_all.py` — 원본 폴더의 기록부 전부를 양식별 코드 없이 정리 (서식 8가지 + 예시 값 + 오류 수식 IFERROR + 시험기한 DAY() 버그)
- `extract_master.py` — 결과 칸(불검출 수식)·검출한계·정량한계·시험방법·단위·자릿수를 찾아 기준표로
- `apply_master.py` — 기준 시트·결과 수식 통일·초과·조건부 서식·산소 보정 연동·원문 대조 반영 (완성본 원본)
- `o2_excess.py` — 허가배출기준 읽기·초과 표시·조건부 서식·표준산소 칸 찾기
- `ref_rules.py` — 공정시험기준 원문 텍스트에서 결과 자릿수·제시 방법검출한계·정량범위·단위를 읽음 ("~을 따른다" 원문, 중금속 표 포함)
- `check_master.py` — 기준표를 총칙·정도보증·물질별 원문과 대조
- `boundary_test.py` — 불검출 경계값 시험 (검출한계와 같음 → 값, 반올림해 같아짐 → 값, 반올림해 작아짐 → 불검출)
- `excess_test.py` — 초과(같음 → 아님, 1단위 큼 → 초과)·조건부 서식·표준산소 연동 시험
- `build_program.py` + `program_template.html` — 시험기록부 프로그램(HTML 한 파일: 기록부·원문 그림·JSZip 내장)
- `wrap_blank_errors.py` — 빈 양식 오류 막기: 입력 숫자를 지운 사본을 엑셀처럼 다시 계산해 오류 나는 수식을 IFERROR(…,"")로 (apply_master 다음)
- `blank_scan.py` — 검증 방식 13: 엑셀 오류 찾기 (그대로·빈 양식)
- `raw_layout.py` — 계산과정 시트 인쇄: 표·차트 묶음이 쪽 사이에서 갈라지지 않게 나누고(긴 표는 차트·병합 칸을 피해 나누고 머리 줄 반복), 열·줄을 늘려 쪽을 채움(그림·차트는 크기 고정). 기기 자료 붙이는 시트(수식 없는 시트)는 손대지 않음 (`is_raw_paste`)
- `equations.py` + `eq_render.cjs` + `eq/` — 계산식: 기록부마다 제각각이던 식(엑셀 수식 개체·칸과 테두리로 만든 분수·글자)을 KaTeX로 조판한 한 모양의 그림으로, 기호 설명도 식과 같은 기호·콜론 맞춘 표 그림으로 (내용은 원본 그대로, 단위 표기만 통일). 그림은 `eq/`에 들어 있고, 식·설명을 바꿨을 때만 다시 만든다:
  `SCRATCH=<katex 설치 폴더의 부모> python3 -I equations.py render` (식), `LEGEND_COLLECT=x.jsonl python3 -I run_all.py …` 뒤 `python3 -I equations.py legends x.jsonl` (설명)
- `eq_audit.py` — 검증 방식 20: 계산식 그림이 칸 안에 있는지·겹치지 않는지·원래 수식 개체가 남지 않았는지·줄지 않았는지
- `raw_untouched.py` — 검증 방식 17: 기기 자료 붙이는 시트가 원본 그대로인지 (칸·값·서식·글꼴·열 너비·줄 높이·병합·그림·인쇄 설정)
- `text_raw_test.py` — 검증 방식 18: 기기 값에 "-"·"<0.001"·음수가 들어와도 중금속·비소 결과가 나오는지
- `page_audit.py` + `sheet_pages.py` — 검증 방식 19: 모든 시트(기기 자료 시트 빼고) 표 묶음 갈라짐·인쇄 영역 경계에 걸린 병합 칸·쪽 채움, 시트마다 실제 PDF 쪽수와 계산 비교
- `anonymize.py` — 예시 사업장명·시료명 약어를 지어낸 이름으로 (run_all 끝)
- `../suite/vendor/sp_wordmark.js` — 제목 글자 로고 (시료채취 프로그램 로고 꾸밈, 풍경 시간대 색)
- `sig_test.py` — 검증 방식 12: 시험 기초자료 유효숫자 표시 (수식 ↔ 규칙, LibreOffice 인쇄 글자)
- `evidence.py` — 원문 근거 그림: 공정시험기준 PDF에서 결과 자릿수·방법검출한계·정량범위·총칙 조항 문장을 찾아 형광펜 표시해 자른다 (쪽을 넘는 문장은 위아래로 이음)
- `verify_round.sh` — 위 전부를 처음부터 한 번에 돌리는 검증 회차

### 쓰는 법

```bash
python3 -I tools/labform/run_all.py <원본 폴더> work/out
python3 -I tools/labform/ref_rules.py <공정시험기준 텍스트 폴더> work/ref_rules.json
python3 -I tools/labform/apply_master.py work/out work/golden work/master.json
python3 -I tools/labform/wrap_blank_errors.py work/golden
python3 -I tools/labform/anonymize.py work/golden
python3 -I tools/labform/check_master.py work/master.json
python3 -I tools/labform/evidence.py work/ref_zip work/master_checked.json work/evidence.json
python3 -I tools/labform/build_program.py work/golden work/master_checked.json jszip.min.js 시험기록부.html work/evidence.json
```

프로그램: 브라우저로 열면 처음 화면(기록부 카드·원문 대조 요약·판정 기준) → 카드를 누르면 기록부 화면(기준·시험 기초자료 유효숫자 수정, 결과 계산(산소 보정 기록부는 표준산소·실측산소), 원문 대조와 원문 그림). 기록부 하나 또는 전체(zip: 기록부 + 기준표 CSV + 수정 내역)를 내려받는다. 고친 값은 브라우저에 저장되고 JSON으로 백업·불러오기.
