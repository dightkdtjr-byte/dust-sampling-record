시험기록부 프로그램 사용법 (v2.3.0)

1. 여는 법
   「시험기록부.html」을 더블클릭해 크롬·엣지로 엽니다. 인터넷 연결 없이 열립니다.

2. 처음 화면
   - 기록부 19종이 묶음별 카드로 나옵니다 (먼지, 자동측정, 무기가스, 금속, 수은, 유기화합물, 다환방향족탄화수소).
   - 위쪽 숫자: 기준 40항목의 원문 대조 결과 (적합 / 검토 / 부적합) 와 수정한 항목 수. 누르면 해당 기록부만 보입니다.
   - 「전체 기록부 내려받기 (zip)」: 수정한 기준이 들어간 기록부 19종 + 기준표(CSV) + 수정 내역(txt).
   - 카드의 「내려받기」: 그 기록부 파일 하나만 내려받습니다.
   - 아래 「판정 기준」: 결과 칸 규칙과 총칙·정도보증 원문 그림.

3. 기록부 화면 (카드의 「기준 보기」)
   - 기준: 공정시험기준, 계산 자릿수, 최종 자릿수, 단위, 방법검출한계, 정량한계, 시험 기초자료 유효숫자를 바로 고칩니다. 고친 칸은 노란색.
   - 결과 계산: 계산값과 허가배출기준(예: 8(12))을 넣으면 기록부와 같은 수식으로 결과와 계산 과정이 나옵니다.
     산소 보정 기록부(먼지, SOx·NOx·CO, 황화수소, 암모니아, 염화수소, 플루오린, 수은, 비소, 중금속)는
     표준산소농도·실측산소농도 칸이 더 있습니다. 표준산소 칸이 비면 허가배출기준 괄호 안 숫자를 씁니다.
   - 원문 대조: 항목마다 적합 / 검토 / 부적합 / 참고. 「원문」을 누르면 공정시험기준 PDF의 해당 문장 그림
     (형광펜 표시, ES 번호·쪽)이 나옵니다. 「원문 근거」 단추는 그 물질의 근거 그림을 모두 보여 줍니다.

4. 저장
   - 고친 내용은 이 컴퓨터의 브라우저에 자동 저장됩니다.
   - 다른 컴퓨터로 옮길 때: 「백업 저장」으로 받은 파일을 다른 컴퓨터에서 「백업 불러오기」.
   - 「처음 값으로」: 모든 수정 지움. 기록부 화면의 「이 기록부 처음 값으로」: 그 기록부만.

기록부 결과 칸 규칙
- 계산 자릿수까지 계산(그 아래는 버림)한 뒤 최종 자릿수로 한 번 4사5입 (계산 자릿수 = 최종 자릿수 + 1)
  [총칙 1.6·2.14.2 → KS Q 5002 4.2.2.2, 맺음은 한 번에. 예: 0.02496 → 0.024 → 0.02]
- 최종 자릿수로 반올림한 값이 방법검출한계 "미만"이면 불검출, 같으면 검출  [총칙 2.14.3, 2.13.6]
- 허가배출기준(괄호 앞 숫자)보다 크면 "(초과)", 빨간 글씨와 연한 빨강 바탕. 같으면 초과 아님
- 허가배출기준 괄호 안 숫자는 표준산소농도(%): 기록부 표준산소 칸에 연결, 초과 판정은 보정값으로
- 실측산소는 표준산소가 있을 때만 씀: 괄호가 없으면 보정하지 않은 값, 괄호가 있는데 실측산소가 비면 결과 칸에 "실측산소 입력"
- 허가배출기준 칸이 "해당없음"처럼 숫자가 아니면 초과 판정 안 함
- 분석하지 않은 값(입력 칸 빈칸)은 평균에서 빼고, 0이나 n.a.(검출 안 됨)는 0으로 평균에 넣음. 모두 비면 결과 빈칸
- 시험 기초자료의 방법검출한계·정량한계: 값을 길게 적어도 물질마다 정한 유효숫자 개수로 표시
  [정도보증 4.3.4.4 「유효 숫자는 2개 이하로 표기한다」]. 개수는 방법검출한계·정량한계 따로, 기본값은 원문 제시값의 유효숫자
  (예: 구리 0.016 → 2개, 0.05 → 1개 / 0.000563 → 0.00056, 0.00996 → 0.01). 원문 제시값이 없는 물질은 입력값 그대로.
  프로그램 기록부 화면 「검출한계 유효숫자」「정량한계 유효숫자」 칸이나 엑셀 「기준」 시트 L·M열에서 바꿈. 저장값은 그대로
- 입력 전·일부만 입력한 칸은 오류(#DIV/0!·#VALUE!) 대신 빈칸
- 예시 값: 사업장명은 지어낸 이름, 날짜는 2000.00.00 꼴
- 황산화물·질소산화물·일산화탄소·총탄화수소: 원문에 방법검출한계 제시값이 없어 불검출 판정 안 함

엑셀에서 기준을 직접 고칠 때: 시트 탭 오른쪽 클릭 → 숨기기 취소 → 「기준」 시트.
