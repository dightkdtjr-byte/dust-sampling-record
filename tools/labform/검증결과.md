# 시험기록부 기준 관리 v1.1.0 — 검증 결과

대상: 시험기록부 19개 파일, 시험항목 38종(암모니아 시험법 3가지 포함 기준 40줄), 결과 칸 42개
근거: 대기오염공정시험기준 161개 원문(총칙 ES 01000.b, 정도보증 ES 01001.b, 물질별 시험법)

## 판정 규칙 (모든 기록부 결과 수식이 같은 규칙)

1. 계산값 → 계산 자릿수로 4사5입 → 최종 자릿수로 표시 (계산 = 최종 + 1) — 총칙 2.14.2
2. 방법검출한계 **미만**만 불검출, **같으면 값** — 총칙 2.14.3. 판정은 판정 자릿수(최종 자릿수와 검출한계 소수 자릿수 중 큰 쪽)
3. 허가배출기준(괄호 앞 숫자)보다 **크면** " (초과)" + 빨간 글씨·연한 빨강 바탕. 같으면 초과 아님. 불검출이면 초과 표시 안 함
4. 허가배출기준 괄호 안 숫자 = 표준산소농도 → 기록부 표준산소 칸에 자동 연결, 초과 판정은 보정한 값으로
5. 요약 시트(결과를 가져와 보여 주는 칸)도 같은 빨간 서식

## 원문 대조로 고친 것

- 아세트알데히드·포름알데히드: 최종 4자리 → **계산 4·표기 3자리** (ES 01501.1d)
- 이황화메틸 단위 pbb → **ppb** (ES 01521.a, 기록부 안 같은 오타 포함)
- 트라이클로로에틸렌 시험방법 ES 01514.1d → **ES 01511.1d** (공정시험기준 칸 값과 같은 원문)
- 수은 시험방법 ES 01408.1d → **ES 01408.1e** (받은 원문 버전)
- 베릴륨 시험방법 "ES 01409. 2" → "ES 01409.2" (띄어쓰기 오타)
- 불검출 판정: 반올림 전 값 비교(검출한계와 같아질 값도 불검출)·중금속/비소 "같으면 불검출" → 규칙 2로 통일
- 시험기한 수식 DAY() 버그 33곳, 원본의 오류 수식(#REF!·#DIV/0!) IFERROR

## 물질 이름·시험방법 (공정시험기준 표기로 통일)

1.3-뷰타다이엔, 1,2-다이클로로에테인, 다이클로로메테인, 트라이클로로에틸렌, 클로로폼, 아크릴로나이트릴, 스타이렌, 염화바이닐,
플루오린화합물, 브로민화합물, 사이안화수소, 폼알데하이드, 아세트알데하이드, 크로뮴화합물 (원문에서 직접 확인한 표기)
- 글자 칸·수식·시트 이름(크로뮴화합물)·요약표·인쇄 범위 이름·파일 이름까지 함께 바꿈
- 시험방법 칸은 ES 번호 뒤 제목을 받은 원문 제목으로 (번호만 있던 칸은 제목을 붙임, "ES01310" → "ES 01310")
- 1.3-뷰타다이엔: 원문이 19곳 모두 "1.3-"으로 씀. 아세트알데하이드: 원문 표에 영문만 있어 "폼알데하이드" 표기법을 따름

## 공정시험기준 칸과 시험 기초자료

- 공정시험기준 칸(불검출 판정에 쓰는 방법검출한계·정량한계) = 원문 제시값과 같아야 함
- 시험 기초자료(실험실 측정 방법검출한계·정량한계) ≤ 원문 제시값 (각 시험법 6.1)
- 불검출 = 공정시험기준 방법검출한계 **미만** (총칙 2.14.3, "미만"은 기준 숫자를 포함하지 않음: 2.13.6)
- 트라이클로로에틸렌: 시험방법을 ES 01511.1d로 통일 (0.03 / 0.1과 같은 원문, 사용자 결정).
  참고: 개별 시험법 ES 01514.1d는 0.10 / 0.30이고, 총칙 1.8은 결과가 갈리면 항목별 공정시험기준 1법으로 판정한다고 함

## 확인해 주실 것

1. **브로민화합물**: 원문은 결과를 소수 1자리로 표기하는데 방법검출한계는 0.04. 0.04~0.049는 검출로 판정되지만 표시는 "0.0"
2. **SOx·NOx·CO 5 ppm, 총탄화수소 3 ppm**: 원문에 방법검출한계 제시값이 없음 (공정시험기준 칸에 기초자료 값이 들어가 있음).
   총탄화수소 정량범위는 본문에 없고 부록 요약표에만 "0.1 ppm 이상"
3. 시험 기초자료가 비어 있음(0): 이황화탄소, 비소화합물, 사이안화수소, 이황화메틸
4. 허가배출기준 라벨이 양식마다 "허가배출기준·배출허용기준·배출허가기준" (모두 인식, 글자는 그대로)
5. 폼알데하이드: 원래 양식에서 차트가 표 위에 겹쳐 있어 자리를 옮기지 않음
6. 받은 기록부는 38종(말씀하신 43종과 차이)
7. 계산은 LibreOffice와 fast-formula-parser로 확인. 실제 Excel에서 한 번 열어 봐 주세요
