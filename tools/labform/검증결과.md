## 판정 규칙 (모든 기록부 결과 수식이 같은 규칙)

1. 계산값 → 계산 자릿수로 4사5입 → 최종 자릿수로 4사5입 (계산 = 최종 + 1), 총칙 2.14.2
2. 최종 자릿수로 반올림한 값이 방법검출한계 **미만**이면 불검출, **같으면 검출**. 총칙 2.14.3, 2.13.6
3. 허가배출기준(괄호 앞 숫자)보다 **크면** " (초과)" + 빨간 글씨·연한 빨강 바탕. 같으면 초과 아님. 불검출이면 초과 표시 안 함
4. 허가배출기준 괄호 안 숫자 = 표준산소농도: 기록부 표준산소 칸에 연결, 초과 판정은 보정값으로
5. 요약 시트(결과를 가져와 보여 주는 칸)도 같은 빨간 서식

## 원문 대조로 고친 것 (누적)

- 아세트알데하이드·폼알데하이드: 최종 4자리 → **계산 4·표기 3자리** (ES 01501.1d)
- 이황화메틸 단위 pbb → **ppb** (ES 01521.a, 기록부 안 같은 오타 포함)
- 트라이클로로에틸렌 시험방법 ES 01514.1d → **ES 01511.1d** (공정시험기준 칸 값과 같은 원문)
- 수은 시험방법 ES 01408.1d → **ES 01408.1e** (받은 원문 판)
- 베릴륨 시험방법 "ES 01409. 2" → "ES 01409.2" (띄어쓰기 오타)
- 불검출 판정 통일, 시험기한 수식 DAY() 버그 33곳, 원본 오류 수식(#REF!·#DIV/0!) IFERROR
- 자동측정법(SOx·NOx·CO)의 측정범위 "0 ~ 1 000 ppm"을 정량범위 하한 0으로 읽던 것 제외 (프로그램의 "정량범위 하한 0" 표시)

## 확인해 주실 것

1. **수치 맺음(반올림) 방식**: 지금 결과 수식은 계산 자릿수로 한 번 반올림한 값을 다시 최종 자릿수로 반올림합니다 (2단계).
   총칙 1.6·2.14.2가 따르라는 KS Q 5002 4.2.2.2 4사5입법의 내용을 담은 KS A 3251-1 부속서 1 「수치의 맺음법」 해설은
   "맺음은 한 번에 하여야 함 (5.346 → 5.3 옳음, 5.346 → 5.35 → 5.4 틀림)"이라고 씁니다.
   받은 원본 기록부도 모두 ROUND(값, 최종 자릿수) 한 번이었습니다 (172개 수식).
   - 차이 나는 값: 계산 자릿수 자리가 4이고 그 아래가 5 이상인 경우 (약 5%). 예) 0.0249 → 지금 0.03, 한 번 맺음 0.02
   - 불검출 판정도 달라질 수 있음. 예) 방법검출한계 0.03에서 계산값 0.0249: 지금 검출 0.03, 한 번 맺음 불검출
   - 고르시면 바로 바꿉니다: (가) 한 번 맺음 (원본·KS 방식, 계산 자릿수 값은 기록용) (나) 지금처럼 2단계
2. 시험 기초자료 0: 이황화탄소(검출·정량), 비소화합물 입자상(검출), 사이안화수소(검출·정량), 이황화메틸(검출). 원본 기록부에도 0
3. 허가배출기준 라벨이 양식마다 "허가배출기준·배출허용기준·배출허가기준" (모두 인식, 글자는 그대로)
4. 폼알데하이드: 원래 양식에서 차트가 표 위에 겹쳐 있어 자리를 옮기지 않음
5. 아세트알데하이드·폼알데하이드·수은: 차트를 찌그러뜨리지 않으려고 3쪽 유지
6. 계산은 LibreOffice와 fast-formula-parser로 확인. 실제 Excel에서 한 번 열어 인쇄 미리보기를 봐 주세요 (쪽 나눔 여유 6%)
