대상: 시험기록부 19개 파일, 시험항목 38종(암모니아 시험법 3가지 포함 기준 40항목), 결과 칸 42개
근거: 대기오염공정시험기준 161개 원문(총칙 ES 01000.b, 정도보증 ES 01001.b, 물질별 시험법)

## v2.3.1에서 바뀐 것

### 기기 자료 붙이는 시트는 손대지 않음
- 수식이 하나도 없는 시트 = 기기에서 내보낸 것을 그대로 붙여 넣는 곳 (rawdata·RAW_DATA·Raw data·rawdata(As)·중금속 검정곡선·PAHs 물질별 기기 출력 6개, 21개 시트)
- 이 시트들은 칸·값·서식·글꼴·열 너비·줄 높이·병합·그림·인쇄 설정 모두 원본 그대로 (예시 사업장명 익명화만). v2.3.0에서는 값과 칸 위치는 같았지만 칸 맞춤·날짜 표시·글꼴·인쇄 설정·그림 배치를 바꿨었음 → 되돌림
- 검증 방식 17로 원본과 하나하나 비교: __RAW__

### 중금속·비소: 기기 값이 "-"이거나 음수일 때
- 원래: 기기 값이 "-" 같은 글자면 평균이 안 나와 최종 농도와 기록부 결과가 빈칸. 음수를 0으로 바꿀 때 글자 "0"이 들어가 같은 줄에 0.0000과 0이 섞이고, 글자 "0"은 엑셀에서 어떤 숫자보다 크게 비교돼 불검출 판정이 틀어질 수 있음
- 고침 (계산과정 시트만): 기기 값이 숫자가 아니면("-", "<0.001", "N/A") 0(불검출)으로, 숫자 모양 글자("5")는 숫자로. 빈 칸은 그대로 빈칸. 음수 → 숫자 0 (중금속 21칸·비소 3칸·수은 1칸·먼지 1칸). 수은 표준산소 "X" 표식은 원래 기능이라 그대로
- 검증 방식 18 (사본에 값을 넣고 다시 계산): __TEXT__. 구리 시료 5 mg/L(글자 '5' 포함) → 0.500 mg/Sm³ (5×100/1000.7 손계산과 같음)

### 계산식
- 원래: 기록부마다 식 모양이 제각각 (엑셀 수식 개체 11곳은 글꼴·크기가 들쭉날쭉하고 비소는 상자에 안 들어가 `C=((m_1+m_2)`처럼 잘림, 사이안화수소·암모니아·페놀·황화수소·수은은 칸과 테두리로 분수를 그림, 총탄화수소는 글자만)
- 고침: 모든 식을 KaTeX(LaTeX 조판)로 그린 한 모양의 그림으로 (분수·아래첨자, 같은 글꼴·크기, 엑셀·PDF 어디서나 같게). 식 내용은 원본 수식 개체·칸 글자 그대로 옮김. 원본 오타 "사인화수소" → 사이안화수소, PAHs 식 머리의 (mg/Sm³)는 결과 단위(ng/Sm³)와 달라 C로 (설명 C : 시료 중 농도 (ng/Sm³))
- 기호 설명: 기호를 식과 같은 조판(Ais → A_is, Θm → θ_m, Vm(std) → V_m(std))으로, 콜론을 세로로 맞춘 표 그림. 설명 글은 원본 그대로, 단위 표기만 통일 (ug/mL → μg/mL, m3 → m³, mmH2O → mmH₂O, Cl- → Cl⁻, 괄호 앞 띄어쓰기)
- 중금속 금속별 시트는 식 줄(12·13행)이 20pt라 식이 테두리에 붙어 30pt로, 아래 설명 줄을 그만큼 줄임 (항목 높이 그대로라 쪽 나눔 같음)
- 검증 방식 20: __EQ__

### 인쇄
- 기록부: 배율을 66 %로 고정. "한 쪽 너비에 맞춤"은 엑셀(맑은 고딕)에서 약 71 %로 잡혀 쪽 높이 계산(67 % 가정)보다 커서, 엑셀에서는 수은·시안화수소·암모니아(H2O2)의 쪽 끝 표가 다음 쪽으로 밀려 갈라질 수 있었음
- 중금속 금속별 7개 시트 3쪽 → 2쪽, VOCs 요약 2쪽 → 1쪽
- 황화수소 기록부 D10:M10 병합이 인쇄 영역(L열) 밖까지 걸쳐 글자가 반쪽만 찍힘 → D10:L10
- 계산과정 16개: 표·차트 묶음이 쪽 사이에서 갈라지지 않게 쪽을 나누고, 열 너비·줄 높이를 늘려 쪽을 채움 (줄은 찍힌 높이 약 1.5 cm까지, 그림·차트는 크기 고정이라 비율 그대로). 한 쪽보다 긴 총탄화수소 계산과정은 3쪽, 머리 줄 반복, 차트·병합 칸을 피해 나눔. 줄이 7~8개뿐인 황화수소·시안화수소·페놀은 쪽 가운데에
- 황화수소·시안화수소 계산과정은 마지막 머리글 병합(P:Q)이 인쇄 영역 밖으로 잘려 있었음 → 영역을 병합 끝까지
- 검증 방식 19 (기기 자료 시트 뺀 56개 시트): __PAGES__

### 처음부터 끝까지: 원문 식 계산기 ↔ 엑셀 (v2.2.8)
엑셀 수식을 보지 않고 공정시험기준 식(각 ES 8.0 결과보고, 표준상태 환산, 총칙 맺음)만으로 계산기를 따로 만들어, 원자료 칸(기기 농도·여지 무게·시료채취량·온도·압력·산소)에 무작위 값을 넣은 엑셀 결과 칸 글자와 견줌 (검증 방식 16). 19개 기록부 42개 결과 칸 × 12세트 = 504건 모두 같음.
- 찾은 것 1: 암모니아 (전체) — 표준산소가 없으면 결과가 늘 「불검출」. 원본 수식의 MAX(K21:L32)="" 비교가 늘 거짓이라 0이 됨 → 보정값이 없으면 보정 전 값의 큰 값, 실측산소가 비었으면 「실측산소 입력」
- 찾은 것 2: 비소 — 기록부 표준산소 칸(K18)에 직접 적으면 결과 빈칸. 계산과정 시트의 표준산소 식이 시트 이름 없이 K18을 읽어 자기 시트 칸을 봄 → 기록부 시트 이름을 붙임
- 그대로 둔 것 (사용자 결정): 원문 식의 고정 값(시료 용액 100 mL, 250/25, 250/10)은 공정시험기준에서 정한 부피라 수식에 숫자로 둠. 시료량 환산은 건식 가스미터 식만 (습식 수증기압 보정 없음)
- 벤조(a)피렌 (v2.2.9): ES 01525.1a 전문을 읽고 대조 (식은 PDF 그림을 보고 확인). 식 9 RRF = An/Ais × Cis/Cn (B43), 식 10~12 평균·RSD (B51·B52), 식 13 C = As/Ais × Iis/RRFavg × 1/Vm (I21), 식 14 C = Cs − Cb (J21), 회수율 식 3~8 (C43·E43·F43, C71·E71·F71) 모두 같음. 다른 곳: 검증시료 RRF(B57·B58)가 다른 주입의 내부표준 면적으로 나눔 → 같은 주입의 값으로. 남은 확인: 내부표준물질 양 1500 ng (원문 표 3 예시는 0.5 μg), 원문에 없는 「벤조(a)피렌 회수율」 칸(B71~)은 그대로
- 원문을 읽은 범위: 전문을 읽은 것은 벤조(a)피렌. 농도식을 PDF에서 본 것은 사이안화수소·비소·브로민. 나머지는 자릿수·방법검출한계·정량범위를 원문에서 뽑아 대조했고 농도식은 화학식량으로 맞는지만 확인

### 결과 경로 재검증 (v2.2.7)
결과 칸마다 값이 거쳐 오는 칸을 끝까지 따라가며(1222칸) 본 것 (검증 방식 15).
- 이황화탄소·이황화메틸 최종 결과값(H32:H37): 원본부터 숫자 0으로 박혀 있어 시료 농도가 결과에 들어가지 않음 → 시료 농도 × 희석배수 (이황화탄소는 시료 농도 ppm × 1000 = ppb, 표준가스 5.01 ppm·검정곡선 0.25~2.5로 확인). 분석 안 한 줄은 평균에서 빼고 바탕을 분석하지 않았으면 0. 확인: 이황화탄소 0.2847·0.2853·0.2850 → 0.29, 이황화메틸 5.2·5.4·바탕 0.2 → 5.1
- 경로 위 반올림(맺음은 결과 칸에서 한 번): 암모니아(전체)가 다시 읽는 보정값 표시 칸(2자리 반올림 → 버림), 염화수소 시료량(2자리 반올림 제거), VOCs 결과값·바탕 평균, 총탄화수소 기기값. 고친 뒤 0칸

### 엑셀 오류 잡기 (v2.2.5)
LibreOffice 검사를 엑셀처럼 바꿈 (빈 글자 "" 계산은 0이 아니라 #VALUE!, 숫자 모양 글자만 숫자로). 그동안은 LibreOffice가 너그러워 엑셀에서만 나는 오류를 놓쳤음.
- 총탄화수소 계산과정 Time(B2:B121): `TIMEVALUE(MID(…))`는 기기 파일 시각 앞 공백·엑셀 지역 설정에 따라 #VALUE! → 시·분·초를 숫자로 꺼내 `TIME()` (엑셀이 날짜로 바꿔 넣은 값도, 빈칸도 처리). 측정 수 × K(E열)도 빈 시각은 빈칸
- 총탄화수소 E122(평균 × K): 공유 수식 원본을 바꾸며 수식이 비던 것을 막음 (수식을 바꾸기 전에 공유 수식을 칸마다 풂). 빈 수식 칸 검사 추가
- 일부만 입력: 암모니아 보정값 표시(K24·K30), 브로민·플루오린 시료 평균(F21, 염화수소와 같게), VOCs 바탕 뺀 값(P열)·시료명(B32:B34), 알데하이드 반복 평균(C8·C11·C14·C17)
- 빈 양식: 입력 숫자를 모두 지운 사본에서 오류 나는 수식 355칸을 `IFERROR(…,"")`로 (값을 다 넣으면 계산은 그대로)
- 확인 (검증 방식 13): 그대로 0칸, 빈 양식 기록부 시트 0칸, 일부만 입력(방식 11의 60가지) 모든 시트 0칸

### 시험 기초자료 유효숫자 (v2.2.4)
시험 기초자료(실험실이 측정한 방법검출한계·정량한계)는 판정하지 않고, 엑셀이 정한 유효숫자 개수로 표시합니다 (정도보증 ES 01001.b 4.3.4.4 「유효 숫자는 2 개 이하로 표기한다」, 공정시험기준의 유효숫자 규정은 이것 하나. 대기환경 ES 01209의 「세 자리」는 배출가스 기록부와 관계없음).
- 개수: 물질마다, 방법검출한계·정량한계 따로. 숨김 「기준」 시트 L열(방법검출한계)·M열(정량한계), 프로그램에서도 고침
- 기본값: 원문 제시값의 유효숫자 (구리 0.016 → 2·0.05 → 1, 납 0.008 → 1·0.025 → 2, 암모니아 0.4 → 1·1.2 → 2, PAHs 3.2 → 2·10 → 2), 많아야 2. 원문 제시값이 없는 SOx·NOx·CO·총탄화수소는 빈칸 = 입력값 그대로 (5는 5)
- 방법: 값 크기마다 소수 자릿수를 정하는 조건부 서식. 자릿수 = MAX(0, S−1−INT(LOG10(|S개로 맺은 값|))) (0.00996을 1개로 → 0.01처럼 자리가 올라가도 맞게). 결과 수식은 이 칸을 읽지 않아 저장값은 그대로. 세 자리 이상 정수(123을 2개로)는 서식으로 줄일 수 없어 정수로 표시
- 확인 (검증 방식 12): 수식 ↔ Decimal 규칙 8만 건 (경계 0.00995·9.95 포함), 모든 기록부 시험 기초자료 칸에 값을 넣어 LibreOffice로 인쇄한 글자 확인 (예: 0.0005630351을 2개로 → 0.00056, 6.979 → 7.0, 0.04951을 1개로 → 0.05)

### 결과 계산의 산소 보정 (v2.2.4)
산소 보정 기록부(먼지, SOx·NOx·CO, 황화수소, 암모니아, 염화수소, 플루오린, 수은, 비소, 중금속)는 결과 계산에 표준산소농도·실측산소농도 칸. 기록부와 같은 규칙: 표준산소가 없으면 보정하지 않은 값, 표준산소가 있고 실측산소가 비면 「실측산소 입력」, 둘 다 있으면 계산값 × (21 − 표준산소) / (21 − 실측산소). 표준산소 칸이 비면 허가배출기준 괄호 안 숫자. 확인: 검증 방식 10에 산소 보정 조합 약 1200건 추가

### 분석하지 않은 값 (사용자 결정, v2.2.3)
엑셀은 빈 칸을 가리키는 수식(=B11)이나 빈 칸의 곱(B×C)을 0으로 계산해서, 분석하지 않은 시료·반복이 0으로 평균에 들어가 결과가 작아졌습니다.
규칙: **입력 칸이 비면 평균에서 뺌, 0이나 n.a.(이온크로마토그래피 "피크 없음" = 검출 안 됨)는 0으로 넣음.** 모두 비면 결과 빈칸.

## 판정 규칙 (모든 기록부 결과 수식이 같은 규칙)

1. 계산값 → 계산 자릿수까지 계산(아래는 버림) → 최종 자릿수로 한 번 4사5입 (계산 = 최종 + 1), 총칙 1.6·2.14.2 → KS Q 5002 4.2.2.2
2. 최종 자릿수로 반올림한 값이 방법검출한계 **미만**이면 불검출, **같으면 검출**. 총칙 2.14.3, 2.13.6
3. 허가배출기준(괄호 앞 숫자)보다 **크면** " (초과)" + 빨간 글씨·연한 빨강 바탕. 같으면 초과 아님. 불검출이면 초과 표시 안 함
4. 허가배출기준 괄호 안 숫자 = 표준산소농도: 기록부 표준산소 칸에 연결, 초과 판정은 보정값으로
5. 요약 시트(결과를 가져와 보여 주는 칸)도 같은 빨간 서식

## 원문 대조로 고친 것 (누적)

- 아세트알데하이드·폼알데하이드: 최종 4자리 → **계산 4·표기 3자리** (ES 01501.1d)
- 이황화메틸 단위 pbb → **ppb** (ES 01521.a, 기록부 안 같은 오타 포함)
- 트라이클로로에틸렌 시험방법 ES 01514.1d → **ES 01511.1d** (공정시험기준 칸 값과 같은 원문)
- 수은 시험방법 ES 01408.1d → **ES 01408.1e** (받은 원문 판)
- 베릴륨 시험방법 "ES 01409. 2" → "ES 01409.2" (띄어쓰기 오타)
- 불검출 판정 통일, 시험기한 수식 DAY() 버그 33곳, 원본 오류 수식(#REF!·#DIV/0!) IFERROR
- 자동측정법(SOx·NOx·CO)의 측정범위 "0 ~ 1 000 ppm"을 정량범위 하한 0으로 읽던 것 제외 (프로그램의 "정량범위 하한 0" 표시)

## 확인해 주실 것

1. 시험 기초자료 0: 이황화탄소(검출·정량), 비소화합물 입자상(검출), 사이안화수소(검출·정량), 이황화메틸(검출). 원본 기록부에도 0
2. 허가배출기준 라벨이 양식마다 "허가배출기준·배출허용기준·배출허가기준" (모두 인식, 글자는 그대로)
3. 폼알데하이드: 원래 양식에서 차트가 표 위에 겹쳐 있어 자리를 옮기지 않음
4. 아세트알데하이드·폼알데하이드·수은: 차트를 찌그러뜨리지 않으려고 3쪽 유지
5. 계산은 LibreOffice와 fast-formula-parser로 확인. 실제 Excel에서 한 번 열어 인쇄 미리보기를 봐 주세요 (쪽 나눔 여유 6%)
