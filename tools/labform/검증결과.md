대상: 시험기록부 19개 파일, 시험항목 38종(암모니아 시험법 3가지 포함 기준 40항목), 결과 칸 42개

고친 것
- 물질 이름 **1,3-뷰타다이엔**: 총칙 1.2.1 표 1(별표8 이름 → 공정시험기준 이름)이 쉼표로 씀. 시험법 문서 제목(ES 01512.1d)은 "1.3-"이라 시험방법 칸은 문서 제목 그대로
- 시험방법 제목: 파일 이름에는 "/"가 없어 빠졌던 것을 PDF 첫 쪽 제목으로 (자외선/가시선분광법, 기체크로마토그래피/질량분석법 등 26개)
- 시험방법 칸 줄바꿈이 괄호 안을 가르지 않게 ("(정전위 / 전해법)" → 괄호째 다음 줄)
- 프로그램: ".05"·"5."·"1E+2" 방법검출한계가 엑셀에 글자로 들어가 불검출 판정이 사라지던 것, 자릿수 빈칸·범위 밖 내려받기,
  한글 입력 중 글자 겹침, 통합 틀 안 로고, 백업 파일을 통한 스크립트 주입, 음수 4사5입(0에서 먼 쪽), 큰 값·지수 표기,
  공정시험기준 칸을 같이 쓰는 줄의 판 대조, 제어 문자로 엑셀 파일이 깨지던 것, 기준 시트 칸 쓰기(빈 칸·없는 칸·없는 줄, 서식 유지),
  잘못된 주소, CSV 엔티티, 계산값 "0.1(12)"·허가배출기준 "1,000(12)" 해석, 빌드 이스케이프
- 방법검출한계가 없는 물질(황산화물 등): 엑셀이 N("-") = 0으로 0 미만을 불검출로 표시 → 프로그램도 같게, 문구 "0 미만만 불검출"

참고 (원문 확인 사항)
- 총탄화수소 정량범위 "0.1 ppm 이상"은 부록 요약표에만 있음 (본문 없음) → 정량한계 "-" 유지
- 먼지 정량범위 0.1 mg/Sm<sup>3</sup>·"방법검출한계: 해당 없음"도 부록에만 있음
- 트라이클로로에틸렌 전용법 ES 01514.1d는 0.10 / 0.30 (지금은 ES 01511.1d의 0.03 / 0.1)
- 아세트알데하이드: 원문 한글 표기는 ES 01111.c의 "아세트알데히드" 한 곳뿐 (ES 01501.1d는 영문). 원본 기록부 표기와 같은 계열인 "폼알데하이드"를 따라 "아세트알데하이드" 유지
- 벤조(a)피렌: 1 000 ng/Sm<sup>3</sup> 이상이면 mg/Sm<sup>3</sup>·계산 4·표기 3자리로 "표기할 수 있다" (ES 01525.1a 8.x)
- 일산화탄소 주 시험방법은 비분산적외선(ES 01304.1b), 기록부는 전기화학식(ES 01304.2c). 자릿수·방법검출한계는 같음

## 판정 규칙 (모든 기록부 결과 수식이 같은 규칙)

1. 계산값 → 계산 자릿수까지 계산(아래는 버림) → 최종 자릿수로 한 번 4사5입 (계산 = 최종 + 1), 총칙 1.6·2.14.2 → KS Q 5002 4.2.2.2
2. 최종 자릿수로 반올림한 값이 방법검출한계 **미만**이면 불검출, **같으면 검출**. 총칙 2.14.3, 2.13.6
3. 허가배출기준(괄호 앞 숫자)보다 **크면** " (초과)" + 빨간 글씨·연한 빨강 바탕. 같으면 초과 아님. 불검출이면 초과 표시 안 함
4. 허가배출기준 괄호 안 숫자 = 표준산소농도: 기록부 표준산소 칸에 연결, 초과 판정은 보정값으로
5. 요약 시트(결과를 가져와 보여 주는 칸)도 같은 빨간 서식

## 원문 대조로 고친 것 (누적)

- 아세트알데하이드·폼알데하이드: 최종 4자리 → **계산 4·표기 3자리** (ES 01501.1d)
- 이황화메틸 단위 pbb → **ppb** (ES 01521.a, 기록부 안 같은 오타 포함)
- 트라이클로로에틸렌 시험방법 ES 01514.1d → **ES 01511.1d** (공정시험기준 칸 값과 같은 원문)
- 수은 시험방법 ES 01408.1d → **ES 01408.1e** (받은 원문 판)
- 베릴륨 시험방법 "ES 01409. 2" → "ES 01409.2" (띄어쓰기 오타)
- 불검출 판정 통일, 시험기한 수식 DAY() 버그 33곳, 원본 오류 수식(#REF!·#DIV/0!) IFERROR
- 자동측정법(SOx·NOx·CO)의 측정범위 "0 ~ 1 000 ppm"을 정량범위 하한 0으로 읽던 것 제외 (프로그램의 "정량범위 하한 0" 표시)

## 확인해 주실 것

1. 시험 기초자료 0: 이황화탄소(검출·정량), 비소화합물 입자상(검출), 사이안화수소(검출·정량), 이황화메틸(검출). 원본 기록부에도 0
2. 허가배출기준 라벨이 양식마다 "허가배출기준·배출허용기준·배출허가기준" (모두 인식, 글자는 그대로)
3. 폼알데하이드: 원래 양식에서 차트가 표 위에 겹쳐 있어 자리를 옮기지 않음
4. 아세트알데하이드·폼알데하이드·수은: 차트를 찌그러뜨리지 않으려고 3쪽 유지
5. 계산은 LibreOffice와 fast-formula-parser로 확인. 실제 Excel에서 한 번 열어 인쇄 미리보기를 봐 주세요 (쪽 나눔 여유 6%)

## 수치 맺음 근거

- 총칙 ES 01000.b 1.6: "공정시험기준에서 사용하는 수치의 맺음법은 따로 규정이 없는 한 한국산업표준 KS Q 5002 (데이터의 통계적 기술) 4.2.2.2 4사5입법의 수치 맺음법을 따른다."
- 총칙 2.14.2: "시험성적수치는 마지막 유효숫자의 다음 단위까지 계산하여 … KS Q 5002 … 4.2.2.2 4사5입법의 수치 맺음법에 따라 기록한다."
- KS A 3251-1 부속서 1 「수치의 맺음법」 해설(표준논단 「유효숫자의 계산방법 및 수치맺음법」): "맺음은 한 번에 하여야 함. 5.346 (유효숫자 2자리로) → 5.3 옳음, 5.346 → 5.35 → 5.4 틀림"
- KS Q 5002 원문은 직접 보지 못함 (유료 표준). 원문 문구를 확인하면 이 문서에 넣을 것
