# 시험기록부 기준 관리 v1.0.0 — 검증 결과

대상: 시험기록부 19개 파일, 시험항목 38종(암모니아 시험법 3가지 포함 기준 40줄), 결과 칸 42개
근거: 대기오염공정시험기준 161개 원문(총칙 ES 01000.b, 정도보증 ES 01001.b, 물질별 시험법)

## 판정 규칙 (모든 기록부 결과 수식이 같은 규칙)

1. 계산값 → 계산 자릿수로 4사5입 → 최종 자릿수로 표시 (계산 = 최종 + 1) — 총칙 2.14.2
2. 방법검출한계 **미만**만 불검출, **같으면 값** — 총칙 2.14.3. 판정은 판정 자릿수(최종 자릿수와 검출한계 소수 자릿수 중 큰 쪽)
3. 허가배출기준(괄호 앞 숫자)보다 **크면** " (초과)" + 빨간 글씨·연한 빨강 바탕. 같으면 초과 아님. 불검출이면 초과 표시 안 함
4. 허가배출기준 괄호 안 숫자 = 표준산소농도 → 기록부 표준산소 칸에 자동 연결, 초과 판정은 보정한 값으로
5. 요약 시트(결과를 가져와 보여 주는 칸)도 같은 빨간 서식

## 원문 대조로 고친 것

- 아세트알데히드·포름알데히드: 최종 4자리 → **계산 4·표기 3자리** (ES 01501.1d)
- 이황화메틸 단위 pbb → **ppb** (ES 01521.a, 기록부 안 같은 오타 포함)
- 수은 시험방법 ES 01408.1d → **ES 01408.1e** (받은 원문 버전)
- 베릴륨 시험방법 "ES 01409. 2" → "ES 01409.2" (띄어쓰기 오타)
- 불검출 판정: 반올림 전 값 비교(검출한계와 같아질 값도 불검출)·중금속/비소 "같으면 불검출" → 규칙 2로 통일
- 시험기한 수식 DAY() 버그 33곳, 원본의 오류 수식(#REF!·#DIV/0!) IFERROR

## 확인해 주실 것

1. **브롬**: 원문은 결과를 소수 1자리로 표기하는데 방법검출한계는 0.04. 0.04~0.049는 검출로 판정되지만 표시는 "0.0"이 됨
2. **SOx·NOx·CO 방법검출한계 5 ppm**: 원문(자동측정법)에 방법검출한계가 없음 (측정범위 0~1000 ppm만)
3. **총탄화수소 3 ppm**: 원문 정량범위 하한 0.1 ppm. 원문은 단위를 "ppm(프로페인 또는 교정가스)"로 쓰라고 함
4. **트리클로로에틸렌 정량한계 0.1**: 원문 정량범위 하한 0.30 ppm (VOCs 공통값을 쓴 것으로 보임)
5. 물질 이름 표기: 기록부 "클로로포름·염화비닐·유도결합플라즈마 분광법" ↔ 원문 "클로로폼·염화바이닐·유도결합플라스마/원자발광분광법"
6. 허가배출기준 라벨이 양식마다 "허가배출기준·배출허용기준·배출허가기준" (모두 인식, 글자는 그대로)
7. 포름알데하이드: 원래 양식에서 차트가 표 위에 겹쳐 있어 자리를 옮기지 않음
8. 받은 기록부는 38종(말씀하신 43종과 차이)
9. 계산은 LibreOffice와 fast-formula-parser로 확인. 실제 Excel에서 한 번 열어 봐 주세요
