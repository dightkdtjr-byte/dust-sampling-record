# 실험실 통합 프로그램

여러 프로그램(시험기록부, 성적서 …)을 **HTML 한 파일**로 묶는다. 처음 화면의 카드나 위 막대에서 골라 연다.

## 원칙: 프로그램은 따로 만들고, 합치기만 한다

- 프로그램마다 **따로 만든 HTML 한 파일**을 그대로 넣는다. 코드를 나누지 않으므로 한 프로그램을 고쳐도 다른 프로그램이 깨지지 않는다.
- 그래서 **채팅(작업)도 프로그램별로 따로** 한다.
  - 시험기록부: 「시험기록부 엑셀 양식 통일」 채팅 → `tools/labform/` → `시험기록부.html`
  - 성적서: 「성적서 관리 프로그램」 채팅 → `성적서발급시스템.html`
  - 통합 파일 만들기는 어느 채팅에서든 `build_suite.py` 한 줄
- 각 프로그램은 통합 화면 안의 틀(iframe, srcdoc)에서 원래 파일과 똑같이 돈다: 브라우저 저장(localStorage)·내려받기·인쇄 그대로.

## 합치는 법

1. 각 프로그램의 최신 HTML을 `tools/suite/apps/`에 둔다 (`apps/`는 저장소에 올리지 않음: 회사 기록부가 들어 있음)
   - `apps/시험기록부.html`
   - `apps/성적서발급시스템.html`
2. `suite.json`에서 제목·카드 설명·색·판 번호를 고친다
3. 만든다

```bash
python3 -I tools/suite/build_suite.py tools/suite/suite.json 실험실프로그램.html
```

파일이 없는 프로그램은 카드에 "아직 합치지 않음"으로 나온다.

## 각 프로그램이 지킬 것 (통합 규칙)

1. **HTML 한 파일**, 인터넷 없이 열림 (글꼴·라이브러리·그림을 파일 안에)
2. **브라우저 저장 키는 프로그램 이름으로 시작**: 시험기록부 `labform-…`, 성적서 `report-…` (같은 저장 공간을 나눠 씀)
3. `window.top`·`parent`를 쓰지 않는다 (통합 화면 밖으로 손대지 않음). 쪽 이동은 자기 안의 `#…`만
4. 내려받기는 `<a download>` + Blob (지금 두 프로그램 방식 그대로)
5. 디자인 기준(시료채취 프로그램과 같은 계열): 먹색 `#2a3944`, 종이 `#fff`/`#f4f5f4`, 바탕 `#eceeec`, 선 `rgba(42,57,68,.16)`,
   카드 둥근 모서리 16px, 알약 단추, 글꼴 IBM Plex Sans KR → 맑은 고딕, 판정 색 적합 `#1f5f43` 검토 `#8a5a00` 부적합 `#b3261e`
6. 화면 문구는 짧은 명사형 (예: "기록부 19종 내려받음"), 위첨자·아래첨자는 `<sup>`·`<sub>` (mg/Sm<sup>3</sup>, NH<sub>3</sub>)

## 시험 (확인한 것)

`통합 화면 → 시험기록부 열기(19종) → 틀 안에서 기록부 내려받기 → 기준 고치면 브라우저 저장 → 성적서로 바꾸기 → 성적서 내려받기
→ 시험기록부로 돌아오면 고친 상태 그대로 → 처음 화면`, 휴대폰 너비(375px)에서 가로 넘침 없음.
